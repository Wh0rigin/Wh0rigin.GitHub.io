## 弱网加载体验

- `index.html` 内置轻量的连线提示，应用脚本未到达时也能显示主题背景；等待较久会提供重新连接按钮。
- 开场动画等待首次路由，不等待图片或 `window.load`。保留日期、涟漪和滑块动画；底部小字“不想等了，直接进入页面”可提前进入，悬停或聚焦时提示资源可能还未加载完成。首次路由等待最多 8 秒，随后由页面的连接提示继续反馈。
- 路由按需加载，等待超过 200ms 才显示提示；加载失败保留当前页面，并提供“重新打开”。
- 图片默认懒加载、预留尺寸、解码后淡入；失败后点击图片可只重试这一张，也支持键盘和手机，恢复网络时重试一次。
- 首页插画使用同站点、带内容哈希的 WebP 和 `srcset`；校徽使用适合显示尺寸的版本。PNG 原图保留，没有改动画面。可用安装了 Pillow 的 Python 执行 `python scripts/optimize-images.py` 重新生成。
- 备用表情延后、低优先级、逐张准备；浏览器报告省流模式、慢速连接或断网时不预下载，也不自动切换表情。

共用连接反馈位于 `src/components/common/ConnectionFeedback.vue`，全站挂载一次；图片与路由通过 `src/composables/loadingExperience.ts` 登记状态。网络判断是浏览器提供的提示，不是测速；不支持网络信息 API 时仍会使用延后加载策略。

## 大屏适配

- 1800px 以上的窗口使用共用的流式字号和内容宽度；在 2560×1444 下，基础字号为 22px、主页内容区为 1600px。三个主题共用这套尺寸。
- 组件的间距、插画尺寸、校徽、按钮和层叠效果使用 `rem`，随字号同步调整；博客文章单独限制阅读宽度。
- 白天加载页在大屏使用同一套日期、圆点和蓝条比例，日期轨道与白线平行；黑夜加载页同步放大标题和进度条。
